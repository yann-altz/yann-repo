# Julia — bientôt

Landing page éditoriale pour annoncer le lancement du parfum Julia.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Modèle du flacon

Placer le modèle fourni ici : `public/parfum.glb`. La page le charge dans sa scène Three.js et synchronise sa rotation avec le défilement. Tant que le fichier est absent, un flacon 3D de remplacement s’affiche.

## Stack

Next.js, React, Tailwind CSS, Motion, Three.js / React Three Fiber, Lottie React et Lucide.
